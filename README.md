# TechMate
Learning management System

A fully functional LMS platform that supports multi-user roles (students and administrators). Developed features for account creation, login, password reset, profile management, and logout.Implemented MongoDB for efficient data storage and retrieval. Developed RESTful APIs using Node.js and Express.js to handle CRUD operations for users, courses, and payments.

Used React's component-based approach to build the UI. Each file like HomePage.js, CourseList.js, or Login.js is a self-contained component responsible for rendering a specific part of the user interface. This makes the code more modular, reusable, and easier to manage.To handle data that changes over time, such as a user's logged-in status or their course progress. Libraries like Redux and useState hook are commonly used for this.
